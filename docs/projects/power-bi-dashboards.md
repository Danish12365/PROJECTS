# 📊 Power BI & Enterprise Business Intelligence Collection

## Executive Summary
This portfolio collection features **7 interactive and published Business Intelligence reports** built using Microsoft Power BI Desktop, Power Query (M Language), and Data Analysis Expressions (DAX). The projects span global public health, energy demand planning, mobile sales operations, entertainment industry analytics, and hospitality demand forecasting.

## Technical Architecture & Design Standards
- **Data Modeling:** Built using Star Schema dimensional modeling principles (Fact tables linked to Dimension tables with 1-to-Many single-direction relationships).
- **DAX Calculations:** Measures include YTD/MTD aggregations, `SAMEPERIODLASTYEAR` time intelligence, percentage variances, and dynamic KPI conditional formatting switches.
- **Power Query (M Language):** ETL transformations, null value handling, data type enforcement, unpivoting columns, and custom column generation.
